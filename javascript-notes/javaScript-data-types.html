Overview

  • In JavaScript, a data type is the kind of value you store like a number or piece of text.
  • Data types help the program understand the kind of data it's working with, whether it's a number, text, or something else.
  • In Javascript there are eight different data types:
    • undefined
    • null
    • boolean
    • string
    • symbol
    • bigInt
    • number: a datatype in JavaScript which represents numeric data
    • object
  • A Number represents both integer and floating-point numbers.
  • A floating point number is a number with a decimal point.
  • An Object is a collection of key-value pairs.
  • Objects are great for grouping related information together.
  • A Symbol is a special type of value in JavaScript that is always unique and cannot be changed
  • A Boolean represents one of two values: true or false
  • Symbol and BigInt are two types that are less commonly used, but they are still important to know about.
  • A String is a sequence of characters, or text, enclosed in quotes
  • BigInt is used for very large numbers that exceed the limit of the Number type
  • null means the variable has been intentionally set to "nothing" and does not hold any value.
  • undefined means a variable has been declared but hasn't been given a value yet.
  • Computers distinguish between numbers and strings which are collections of characters.
  • Computers can perform mathematcial operations on a number but not on a string.
  • Variables allow computers to store and manipulate data in a dynamic fashion.
  • Variables use a label to point to the data rather then using the data itself
  • Any of the eight data types can be stored in a variable
  • Variables are similar to the x and y variables you can use in mathmatics, which means they're a simple name to represent the data we want to refer to
  • Computer variables differ from mathematcial variables in that they can store different values at different times
  • We tell JavaScript to create or declare a variable by putting the keyword var in front of it
