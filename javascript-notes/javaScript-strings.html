Overview

  • String object lets you manipulate strings
  • In JavaScript, a string is a sequence of characters used to represent text data
  • Strings are one of the primitive data types in the language, along with numbers, booleans, null, and undefined.
  • To create a string in JavaScript, you can use single quotes ('), double quotes ("), or backticks (`) for template literals.
  • Even though you can use single or double quotes to create strings, it's important to be consistent. If a string begins with a single quote, it must also end with a single quote.
  • Another thing to take into account is that strings are immutable
  • In programming, immutability means that once something is created, it cannot be changed. So, when you create a string, you can't change its characters directly. Instead, you would create a new string if you want to make changes.
  • Since strings are immutable, we can't update the first string directly. That is why we assign a new string to the variable.
  • In JavaScript, working with text is an essential part of coding, and often, you'll need to combine or join pieces of text together. This process is called string concatenation.
  • In this lesson, we'll focus on how string concatenation works, specifically using the + operator, the += operator, and the concat() method.
  • The + operator is one of the simplest and most frequently used methods to concatenate strings. It allows you to join multiple strings or combine strings with variables that hold text.
  • One disadvantage of using the + operator for string concatenation is that it can lead to spacing issues if you don't carefully manage the spacing between the concatenated strings.
  • If you need to add or append to an existing string, then you can use the += operator. This is helpful when you want to build upon a string by adding more text to it over time.
  • Another way you can concatenate strings is to use the concat() method.

Code Examples

  • let singleQuotes = 'This is a string';
console.log(singleQuotes);

    Single quotes are commonly used to define strings in JavaScript. They are simple and easy to read.

  • let doubleQuotes = "This is also a string";
console.log(doubleQuotes);

    Double quotes can be used interchangeably with single quotes to create strings, but it's important to be consistent within a single string.

  • let templateLiteral = `This is a template literal`;
console.log(templateLiteral);

    Template literals allow for embedded expressions and multi-line strings, making them more versatile than regular strings.

  • let developer = "Jessica";
console.log(developer);
developer = "Quincy";
console.log(developer);

    In this example, we first assign the string "Jessica" to the variable developer. Later, we reassign the variable to a new string "Quincy". This demonstrates that while strings themselves are immutable, variables holding strings can be reassigned to new strings.

  • let firstName = "John";
                    let lastName = "Doe";

                    let fullName = firstName + " " + lastName;
                    console.log(fullName); // John Doe

    In this example, we use the + operator to concatenate the firstName and lastName variables, along with a space in between, to create a full name string.

  • let greeting = 'Hello';
                    greeting += ', John!';

                    console.log(greeting); // "Hello, John!"

    In this example, we use the += operator to append a string to the existing greeting variable, resulting in a new string "Hello, John!".

    It is important to remember that strings are immutable which means once a string is created you can not alter it.

    In this case, the original string of Hello is not modified. Instead, greeting now references the new string of Hello, John!

  • let str1 = 'Hello';
                    let str2 = 'World';

                    let result = str1.concat(' ', str2);
                    console.log(result); // Hello World

    In this example, we use the concat() method to join str1 and str2 with a space in between, resulting in the string "Hello World".
